# francisrath/homebrew-tap

Homebrew tap for [pdb-print](https://github.com/francisrath/partdb-print-agent), the label print agent for Part-DB.

```sh
brew tap francisrath/tap
brew trust francisrath/tap      # Homebrew 7 only loads casks from trusted taps
brew install --cask pdb-print
```

The cask in `Casks/` is generated by GoReleaser on each release of partdb-print-agent; don't edit it by hand.
